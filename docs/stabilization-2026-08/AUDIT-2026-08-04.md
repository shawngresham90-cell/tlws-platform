# Adversarial audit of the integrated candidate — 2026-08-04

Six parallel domain audits (completeness, exit/sitemap, trip-planner safety,
security, main-regression, cache-composition) ran against the integrated
tree (main `f2c0f6a` + #232 + #216), each claimed defect then challenged by
an independent refutation pass. Three findings survived refutation; all
three are fixed in this branch, each pinned by new assertions. Nothing was
weakened to get a pass.

## Confirmed and fixed

1. **Build memo cached failed reads as empty successes** (`data.ts`).
   `getEntriesWithCoordinates`, `getPublishedDetailSlugs` and
   `getRouteFacetsForCategories` swallowed failure into `[]`/empty-facets
   *inside* the memoized function, so the memo's `ok === false` eviction
   could never fire — one transient DB blip during `next build` pinned an
   empty map page / sitemap-detail set / route-facet set for that worker's
   whole build. Fixed by carrying the `DirectoryReadResult` shape *through*
   the memo and applying fail-soft outside it. Pinned structurally and
   behaviorally (eviction on thrown reads now tested too).

2. **`/api/preschool/claim` was widget-wired but not strict** — a bot
   omitting the optional `turnstileToken` bypassed verification entirely,
   on the route feeding the Founding Student wall. The #232 strict-mode
   sweep covered review + submission and missed this one. Fixed:
   `requireTurnstile: true`; pinned in `test-directory-write-guards`.

3. **HERE route cache/coalescing key omitted `departAtMs`** while the
   request URL sends `departureTime` — the provider's answer is
   departure-dependent (traffic, time-of-day truck restrictions), so one
   cached route was served for every departure time for the 6 h TTL,
   labeled as computed for it. Fixed: the key now carries a 30-minute
   departure bucket — near-simultaneous identical quotes still coalesce to
   one billed transaction; a departure hours later spends its own. Pinned
   in `test-here-routing` (key separation + transaction-count behavior).

## Consistency fixes from confirmed minors

- **here-geocode negative-cached provider failures as `[]` for 1 h** —
  unlike the routing adapter. Now only real answers (including a genuine
  200-with-no-items) enter the cache; outages are retried. Pinned.
- **Planner pool accepted an uncorroborated short page** when the pre-scan
  count had failed — the exact terminal-condition inference `data.ts`
  refuses. Now identical policy: short + count ⇒ corroborated stop; short +
  no count ⇒ keep walking to the verified empty page. Pinned (a 100-row
  server cap with no count now returns all 3,000 rows, and the
  one-extra-request cost is asserted, not hidden).
- **`memoKey` folded empty-string filter values into the unfiltered key**
  (`getEntriesByState('')` would have shared the `entries` memo slot with
  the unfiltered read) and did not encode `&`/`=` in values. Fixed; pinned.

## Audit-mandated coverage added

`test-directory-complete-read`: simulated server caps of **500 and 1000**
rows (bound via oversized page requests), **rows removed during a scan**
(refused as `short_pool`), **memo eviction on a thrown read**. Totals:
complete-read 205 → 217, planner-pool 115 → 119, here-routing 66 → 70,
here-geocode 50 → 53, write-guards 9 → 10.

## Confirmed non-findings (attempted, refuted)

React `cache()` cannot leak a failed Result across requests; a first-scan
facet failure cannot poison `generateStaticParams` (fail-soft path
re-reads); the HERE pending map cannot serve TTL-expired entries; `/api/lead`
byte-identical to main except the shared 4 s siteverify timeout (which only
tightens failure behavior — lead has no widget and no token, so its
verification path is unchanged); NEXT_PHASE is assigned exclusively by
`next build` (verified in `node_modules/next/dist`), so the memo is
provably runtime-inert.

## Known limitations documented, deliberately not fixed here

Pre-existing on main and outside this milestone's touched surface:
`getEntryByDetailSlug` collapses query errors into `null` (a detail-page
false-404 vector of the same class #215 fixed for exits); facet trim/case
normalization diverges from the exact-match page query (latent variant-
spelling 404); sitemap regeneration is fail-soft and can emit an empty
directory section for its 1 h revalidate window after a total read failure;
HERE free-tier counter counts `route()` calls rather than HTTP transactions;
the degree-window prefilter is untested above ~89° latitude (CONUS product).
Each is a candidate for its own follow-up; none is made worse by this
branch.
